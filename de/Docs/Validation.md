# 验证记录与效果边界

运行 DLL 与此前在游戏中实测的 v4 文件一致。Special K INI 清除了本机 DLL 地址缓存及 Steam API 绝对路径。

- 原程序集修改 10 个方法、增加 2 个私有缓存字段；其余方法与原有字段保持不变。
- 正式运行模块不含自动读档、自动移动、存档重定向、性能探针或文件轮询。
- 残影逐帧采样、完整顶点更新、暂停恢复及瞬移已做运行测试。
- 缓存路径完成 160 次连续场景数据核对及 128 次交错核对。
- 缓存路径局部 CPU 网格更新时间从 21.28 降至 14.23 微秒，约降低 33%；整体帧率从 441.72 到 440.42 FPS，没有证明整体帧率提升。
- 源码重新构建后的主程序集与发布 DLL 逐字节相同；辅助模块的 16 个方法 IL 与发布版一致，编译元数据可不同。
- 零图形启动参数重新启动游戏后，日志确认默认使用 DX11、多线程渲染（threaded=1），辅助模块正常加载。因此安装器不写入 Steam 启动参数。
- Windows PowerShell 5.1 下完成隔离安装测试：直接覆盖任意原 DLL、重复安装、含空格路径及 Steam 库自动定位；安装和重复安装均不生成备份。Steam 配置保持原样，settings.bin 仅 VSync 字节变化，存档测试文件不变。

本补丁改善显示位置和拖尾更新；原作约 30 FPS 的姿态素材没有生成额外动画帧。显示插值可能增加最多一个物理步（约 16.7 ms）的显示延迟。测试没有覆盖全地图和全部技能，也没有跨硬件证明四核心报告配置总是最优。渲染不限帧并不保证每台电脑每个场景都达到 165 FPS。

安装器测试使用隔离目录与模拟进程接口；零参数启动测试使用本机实际游戏。逐项结果见本目录 JSON。
