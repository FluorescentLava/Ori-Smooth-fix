# 原版验证记录

适用游戏为 Steam AppID 261570，Unity 5.0.0b5，Windows 32 位。

## 测试环境

RTX 5060 Laptop GPU、1920×1080 游戏分辨率、165 Hz 显示器，火山区域存档副本。游戏在无图形启动参数时使用 DX11 和多线程渲染（threaded=1），本地 dxgi.dll 正常加载。

诊断采样通过帧末 Stopwatch 记录应用帧时间，通过 OnPreRender 记录显示坐标。存档副本使用独立目录；原存档及其五个备份和 settings.bin 的七个文件哈希保持一致。

## 显示与时序

| 指标 | 结果 |
| --- | --- |
| 移动样本 | 8,211 帧 / 32.34 秒 |
| 平均应用渲染帧率 | 253.88 FPS |
| 帧时间中位数 | 3.88 ms |
| 帧时间 P99 | 6.98 ms |
| 物理步长 | 1/60 秒 |
| timeScale | 1 |
| 渲染目标 / VSync | -1 / 0 |

在相同物理时间的 6,274 对连续渲染帧中，角色显示坐标有 4,049 对变化，镜头有 6,249 对变化，物理角色坐标变化为零。禁用显示插值和拖尾修改的对照中，16,310 对相同物理时间的连续帧均未出现角色显示或镜头坐标变化。

测试覆盖移动、掉落和检查点恢复。不同模式的路径和场景负载不同，FPS 差值不作为补丁或缓存的性能收益。应用帧时间采样不等于显示器的呈现间隔，也不代表全图稳定 165 FPS。

## 拖尾缓存

引擎网格读回共 240 次：缓存开启 127 次、关闭 113 次，全部匹配。比较项包括完整顶点、UV、UV2、颜色、各子网格四边形索引、sharedMesh、材质引用、贴图及材质参数。四边形索引使用 GetIndices 读取。

网格读回测试独立于性能采样。SpawnSingleTrailSprite 的调用次数仅表示方法调用，不能等同于成功发射数量。详细数据见 [运行汇总](runtime-validation.json)。

## 程序集与安装器

程序集比较覆盖 2,417 个类型和 13,257 个方法，变更范围为 10 个方法与两个缓存字段。辅助模块使用摄像机组件消息进行渲染插值，并配置原生非同步时序；不写入物理步长或刚体状态。

Windows PowerShell 5.1 的隔离安装和重复安装通过。实际安装的两个运行 DLL 与构建文件哈希一致，无参数启动可正常加载辅助模块。运行文件保留原存档目录，不包含诊断引用、自动读档、自动移动或文件轮询。

## 适用范围

测试覆盖局部场景，未遍历全地图、全部技能或全部硬件。角色姿态素材保持原有动画帧数，显示插值可能增加最多一个物理步（约16.7 ms）的延迟。实际帧率、温度和风扇噪声受硬件及场景影响，四核心报告配置未证明对所有电脑最优。
